# Hävstångskartan

Ett verktyg som gör en Excel-logg över hävstångspunkter och möjlighetsfönster till en karta som en grupp prioriterar i. Efter mötet får gruppen en ny Excel-fil med mötets beslut.

Adress: https://havstang.mickla.se

- Loggen läses i webbläsaren och lämnar aldrig datorn. Inget sparas och inget skickas.
- Repot innehåller bara verktyget och en påhittad exempelfil, aldrig riktiga loggar.
